a bit of knowlege to present during the presenting stage on monday:
"When a PC powers on, here’s what the BIOS (or UEFI in modern systems) does:

    Power-On Self Test (POST): Checks CPU, RAM, and basic hardware.

    Boot Device Selection: Based on your BIOS settings or boot order (e.g., USB → HDD → CD), it picks the first device that claims to be bootable.

    Reads Sector 0 (LBA 0): BIOS reads the very first 512 bytes of that device. This is the boot sector — no filesystem is parsed at this point. It doesn't care what format the device is (FAT32, NTFS, ext4 — irrelevant).

    Looks for the Boot Signature:

        It checks if the last two bytes are 0x55 and 0xAA (in that order, little endian: 0xAA55).

        This is a signal that "I’m executable boot code!"

    Loads to memory at 0x7C00: BIOS loads those 512 bytes into memory at address 0x7C00.

    Jumps to 0x7C00: Execution begins — the CPU starts running your 16-bit real mode boot sector code.:
" this will help people understand how the BIOS gets to the bootloader on startup
